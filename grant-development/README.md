# Grant Development

This directory will hold grant-development materials that are distinct from the underlying historical research.

Planned contents:

- partner and host mapping;
- eligibility notes;
- calls and deadlines;
- concept notes and proposal drafts;
- work-package and budget drafts;
- publication, open-data, licensing, and IP considerations;
- go/no-go decisions.

A grant call should be selected only after the research question, scholarly contribution, host/PI model, and proposed outputs are clear.
